# Teaboom — карточка товара «Ананасовый улун»

Адаптивная HTML/CSS/JavaScript-вёрстка верхней части карточки товара по тестовому заданию Teaboom.ru.

## Что реализовано
- Семантическая HTML5-разметка.
- Адаптивная компоновка для desktop, tablet и mobile.
- Переключение фасовки с обновлением цены, старой цены, артикула и выбранного состояния.
- Hover/focus-состояния кнопок и доступные `aria-pressed` состояния фасовки.
- Демо-обработка кнопки «В корзину» без подключения реальной корзины.
- Чистый CSS и JavaScript без frontend-фреймворков.

## Запуск
Откройте `index.html` в браузере. Для локального HTTP-сервера можно выполнить в папке проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация
Проект состоит из статических файлов и может быть опубликован через GitHub Pages или Netlify. После публикации отправьте работодателю ссылку на страницу и ссылку на репозиторий.

## SaleScout: пересчёт цен (reprice)

Дополнительный модуль к проекту: интерфейс с результатами пересчёта цен и API `POST /reprice`.

### Файлы
- `reprice.html` — страница с результатами пересчёта (HTML/CSS/vanilla JS).
- `reprice.css` — адаптивные стили страницы.
- `reprice-ui.js` — загрузка `data/products.json` и отрисовка таблицы.
- `reprice.js` — чистая логика расчёта (общая для браузера и Node.js).
- `server.js` — минимальный backend на встроенном модуле Node.js `http` (без зависимостей): статика + `POST /reprice`.
- `data/products.json` — синтетические тестовые данные (не реальные продавцы и не внешний API).
- `data/expected.json` — ожидаемые результаты, рассчитанные вручную по правилам.
- `tests/reprice.test.js` — тесты логики расчёта.
- `tests/api.test.js` — тесты эндпоинта `POST /reprice`.

### Интерфейс
Локальный сервер для страницы (данные загружаются через `fetch`, поэтому нужен HTTP):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/reprice.html
```

Либо всё вместе (страница + API):

```bash
node server.js
# UI:  http://localhost:3000/reprice.html
# API: POST http://localhost:3000/reprice
```

### Тесты

```bash
node tests/reprice.test.js
node tests/api.test.js
```

### Важно про `POST /reprice`
Требование оригинального задания включает серверный эндпоинт. Браузерное приложение на HTML/CSS/JavaScript само по себе не может создать серверный эндпоинт, поэтому это требование конфликтует с ограничением «только HTML/CSS/JavaScript». Минимальное решение — `server.js` на встроенном модуле Node.js `http` (дополнительные пакеты не устанавливаются). Frontend остаётся чистым HTML/CSS/JS и работает и без backend (расчёт выполняется на клиенте через `reprice.js`).
